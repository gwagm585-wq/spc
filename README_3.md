# 공정 관리 대시보드 (SPC Dashboard)

통계적 공정관리(SPC) 절차를 웹에서 한 번에 수행하는 대시보드입니다.
공정 데이터를 넣으면 **관리도로 공정 안정성을 판정**하고, **공정능력지수로 규격 대비 성능을 평가**한 뒤, 두 결과를 묶어 **개선 방향**을 제시합니다.

**바로 사용해 보기 → https://gwagm585-wq.github.io/spc/**

> 스마트제조 과목(2026년 1학기) 과제로 제작. 설치 없이 브라우저에서 동작하는 단일 HTML 파일입니다.

## 분석 흐름

```
데이터 입력 → 관리도 자동 추천 → 이상신호 탐지(8개 규칙) → 이상 부분군 제거·관리한계 재계산
          → 정규성 검정(Shapiro-Wilk, Q-Q) → 필요 시 Box-Cox 변환 → 공정능력지수(Cp·Cpk·Pp·Ppk)
          → 관리상태 × 공정능력 매트릭스로 개선 방향 진단
```

## 주요 기능

| 구분 | 내용 |
|---|---|
| 관리도 | 계량형 X̄-R, X̄-S, I-MR / 계수형 NP, P, C, U. 데이터 유형·부분군 크기에 따라 적합한 관리도 자동 추천 |
| 이상신호 | 8개 판정 규칙(3σ 이탈, 9점 편향, 6점 추세, 14점 진동 등) 탐지와 규칙별 원인 후보 제시 |
| 관리도 재작성 | 이상 부분군 제거 → 관리한계 재계산 반복, 직전 단계 복구 지원 |
| 공정능력 | Cp, Cpk, Pp, Ppk, Cpm, 예상 불량률(ppm). 군내(σ within)·전체(σ overall) 변동을 분리해 단기/장기 능력 비교 |
| 정규성 | Shapiro-Wilk 검정, Q-Q plot, Box-Cox 변환(최적 λ 탐색) |
| 진단 매트릭스 | 관리상태(관리도) × 공정능력(Cpk)을 4개 사분면으로 나눠, "관리는 되지만 능력 부족" 등 상황별 조치 방향 제시 |
| 시뮬레이션 | 평균 이동·산포·부분군 수를 슬라이더로 바꾸며 지수와 관리도 변화를 즉시 확인 |
| 데이터 | 샘플 프리셋, CSV 업로드(컬럼 매핑), 표에서 직접 수정 |

## 샘플 데이터

- **PVC 점도 (일별)** — 기본 데이터. 일자별 25개 부분군 × 5개 측정. D14에 평균 이동(이상원인)을 넣어 두어, 이상점 탐지 → 제거 → 재계산 흐름을 확인할 수 있습니다.
  - 제거 전: 관리이탈 + 능력 부족(Cpk 1.19) → 제거 후: 관리상태 + 능력 부족(Cpk 1.21) → 산포 축소가 필요한 공정으로 진단
- **PVC 점도 (생산라인별)** — 강의 예제(6개 라인 × 5개). 라인 간 비교·공정능력 계산용
- **웨이퍼 두께 / LED 불량개수** — 계량형 X̄-R, 계수형 NP 관리도 예시(시뮬레이션 생성)

## 설계 메모

- **관리도 부분군은 시간 순서 전제**: 부분군이 시간순이 아닌 데이터(예: 생산라인별)를 불러오면, 관리도가 공정 안정성이 아니라 그룹 간 차이를 보여준다는 경고를 띄웁니다.
- **부분군 수 점검**: 관리한계 추정에 쓰인 부분군이 20개 미만이면 한계선을 참고용으로 보라고 안내합니다.
- **Box-Cox 경계값 처리**: 최적 λ가 탐색 범위(±3) 경계에 걸리면 변환이 적절하지 않다는 경고를 띄우고, 매우 작은 변환 척도 값도 유효숫자로 표시합니다.
- σ within은 부분군 표준편차의 합동(pooled) 추정치에 c4 보정을 적용해 계산합니다.

## 한계

- 이상신호의 원인 후보는 패턴 기반 일반 후보이며, 실제 원인은 현장 확인이 필요합니다.
- 공정능력지수는 정규분포 가정에 기반합니다. 비정규 데이터는 Box-Cox 변환 후 해석하거나 별도 방법이 필요합니다.
- 샘플 데이터는 학습용으로 만든 예시 데이터입니다.
